# SEO и публикация

Основной домен: https://allopharm.ru (латиницей). Задан в `src/seo.js`.
Если окончательный домен будет другим, изменить SITE_URL и заново собрать сайт.

## Что настроено

- Уникальные title и description, canonical, hreflang ru/en/x-default, Open Graph и Twitter metadata.
- Главная на русском — `/`, на английском — `/en/`. Язык определяется адресом, а не сохранённой настройкой браузера.
- Приоритет описаний: бренд Аллофарм / Allopharm, Алломедин Про и сотрудничество. Описания метаданных нейтральные; видимые тексты и PDF не редактировались.
- `npm run build` создаёт HTML каждой индексируемой страницы с текстом и метаданными, `sitemap.xml`, `robots.txt` и `404.html`. React продолжает обеспечивать интерактивность. Бэкенд не нужен.
- Английская страница Аллостатина с русским текстом исключена из sitemap и hreflang, имеет noindex и canonical на русский оригинал. После появления перевода нужно добавить английские метаданные в seo.js.
- Неизвестные адреса получают noindex в приложении. Правильный HTTP-код 404 зависит от настройки хостинга.

## Настройка хостинга при запуске

1. Загружать всю папку `build`, включая вложенные каталоги страниц. Хостинг должен отдавать существующий `/<путь>/index.html` для `/<путь>/` прежде любых SPA-перенаправлений. Не направлять все адреса на главную принудительно.
2. Для отсутствующих файлов/страниц отдавать `404.html` с HTTP 404. Для `/en/allostatin/` и `/allostatin/` настроить постоянный редирект на соответствующий `/allostatins/`. Согласовать HTTPS, www и завершающий слеш: единственный основной вариант — HTTPS без www, страницы со слешем.
3. До переключения домена выгрузить все старые URL WordPress и сопоставить с новыми. Сохранённые адреса оставить; изменённые перенаправлять 301 на соответствующую страницу, не все на главную. Старый `en.allopharm.ru` направлять на соответствующие `/en/` страницы только после проверки соответствий. В том числе проверить старые новости, PDF, изображения и страницу политики конфиденциальности, на которую есть ссылка в футере.
4. Проверить доступ к DNS и сохранить существующие почтовые записи. Подключить SSL. Переключение домена и редиректы этой задачей не выполнялись.
5. Тестовый хост защитить паролем либо серверным X-Robots-Tag: noindex. На основном домене блокировку снять. Canonical сам по себе не запрещает индексировать тестовую копию.
6. Добавить сайт в Яндекс Вебмастер и Google Search Console, подтвердить владение и отправить `/sitemap.xml`. Проверить фактический HTML и HTTP-коды главной, продукта, английской страницы и неизвестного адреса.

## Проверка перед загрузкой

`npm test -- --watchAll=false --runInBand` и `npm run build`.
Проверить переходы RU/EN, ссылки из хедера и футера, главные якоря, новости и PDF.
Не редактировать сгенерированные HTML вручную — следующая сборка их заменит.

Частотность запросов и позиции не измерялись. Настройки создают техническую основу SEO, но не гарантируют позиции или сроки индексации. Ссылка для покупки Алломедин Про пока не предоставлена и не добавлялась.
